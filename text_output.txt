1. HOW EXAM EVENTS WORK
Our partner examiner travels to deliver EASA Part-66 module examinations when we reach minimum viable booking thresholds. Each exam event is scheduled approximately every 3 months and runs over 2-3 days to accommodate multiple exam pools (sittings).
What is an Exam Pool?
An exam pool is a single exam sitting that brings together candidates who may not know each other. Each pool:
• Accommodates 25-28 candidates
• Each candidate takes ONE module per pool
• Supports up to 4 different module codes within the same sitting
• Confirms automatically when 25 candidates have reserved and paid
Example: Pool A might have 7 candidates taking M1, 8 taking M7, 6 taking M8, and 5 taking M15 - all in the same exam session.

3. BOOKING CONDITIONS
Event Confirmation (Go/No-Go Decision)
Go/No-Go Threshold (T-21): An exam event confirms and proceeds when ANY of the following thresholds are met 21 days before the event start date:
• 3 exam pools have reached 25+ confirmed candidates each (€30,000 revenue), OR
• 2 confirmed pools (25+ each) + 15 individual/bundle seats (€27,800+ revenue), OR
• 60 total confirmed paid seats across all booking types (€25,200+ revenue)
Event Postponement: If minimum numbers are not met by the payment deadline (T-21), the exam event is moved to the next available window. All confirmed bookings automatically roll forward at no extra cost.
Pool-Specific Rules
Pool Confirmation: Each pool automatically confirms when 25 candidates have reserved and paid. Pool status is visible in real-time via the Portal.
Pool Capacity: Minimum 25 candidates, maximum 28 candidates per pool. First-come, first-served once you complete payment/reservation.
Module Diversity: Each pool supports up to 4 different module codes. Once a pool reaches 4 distinct modules, new joiners may only select from those existing modules.
Pool Failure: If a pool does not reach 25 confirmed candidates by T-21, it will not run. Candidates receive:
  • Full wallet credit release
  • Option to join another pool in same event (if available)
  • Auto-roll to next event pool at no cost
  • Upgrade to individual seat (+€220 top-up)
Seat Reservation: Pool seats are allocated on a first-reserved, first-confirmed basis once payment clears. Each pool has a hard cap of 28 candidates.
General Booking Rules
Late Booking Surcharge: Bookings made within 14 days of the exam event incur a €50 surcharge per seat (only if space remains). Does not apply to pool seats.
Module Changes: Module change or sitting move after schedule publication is subject to availability and a €50 admin fee. For bundle holders, this admin fee is waived for the included free changes if requested by T-21: 2-seat bundle includes 1 free module change; 4-seat bundle includes 2 free module changes. Pool seats cannot change modules after pool confirmation.
No-Show Policy: No-shows forfeit the seat, as examiner resources are committed once schedules are locked. No refunds for no-shows except where a confirmed medical reason is provided, verified, and accepted by Aerojet; in such cases, Aerojet may issue a wallet credit to the student cash account for future exam use.
4. PAYMENT TERMS
Pool Seats: Full payment (€300) required to reserve pool slot. Funds held in wallet until pool confirms. Automatically captured upon pool confirmation. Released if pool fails.
Individual Seats: 50% deposit to reserve seat. Balance due by T-21 (21 days before the event window). If the balance is not paid by T-21, the 50% deposit is forfeited as an exam deposit, as Aerojet has already locked in exam arrangements as confirmed.
Bundles (2-seat, 4-seat): Paid in full to activate, unless an agreed installment plan is issued in writing by Aerojet admin.

5. CHANGES, POSTPONEMENTS & CREDITS (NO CASH REFUNDS)
Aerojet-Initiated Postponement: If Aerojet postpones an event (minimum numbers not met), all confirmed bookings automatically roll forward as wallet credit to the student cash account for the next available exam window at no additional cost. No cash refunds are provided once a candidate has committed to any exam booking.
Candidate-Initiated Changes: See Module Changes section above. €50 admin fee applies except where waived for bundle holders.
Cancellation by Candidate: Cancellations made more than 21 days before the event: eligible for wallet credit only (credited to the student cash account) at Aerojet’s discretion. Cancellations within 21 days: no credit (examiner commitment locked). Pool seat cancellations: wallet credit retained until pool confirms or fails.
