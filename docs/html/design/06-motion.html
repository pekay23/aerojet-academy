Design

06 · Motion & interaction

The portal deliberately keeps motion short, restrained, and purposeful — no parallax, no scroll-jacking, no long reveals.

  • Skeleton from shadcn: animate-pulse rounded-md bg-muted.
  • aria-busy is set on busy buttons (ChangePasswordForm, calendar save button).
  • Buttons in a busy state get disabled:opacity-50 disabled:pointer-events-none plus the same aria-busy attribute.
  • A few components toggle a tiny "PROCESSING…" / "SAVING…" caption via aria-live="polite".
