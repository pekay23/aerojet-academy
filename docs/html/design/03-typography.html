02 · 3.2 · Tailwind font family aliases

3.2 · Tailwind font family aliases

font-sans → var(--font-inter) → system-ui → sans-serif font-outfit → var(--font-outfit) → sans-serif font-heading → var(--font-cal) → var(--font-inter) → system-ui → sans-serif font-serif → var(--font-playfair) → Georgia → serif
font-heading is declared but the --font-cal variable is not loaded in app/layout.tsx yet — it falls through to Inter. Consider this a stub for a future "Cal Sans" or similar.
