Setup Guide

01 · Prerequisites

Prerequisites

Node.js >= 24.0.0Bun >= 1.0.0 (package manager)PostgreSQL database (Neon recommended)
02 · Installation

Installation

git clone cd aerojet-academy bun install
03 · Environment Configuration

Environment Configuration

cp .env.example .env.local # Edit .env.local with your database URL, API keys, etc.
04 · Database Setup

Database Setup

bun run db:generate # Generate Prisma client bun run db:push # Push schema to database bun run db:seed # Seed with core system data bun run db:seed:mock # Seed with high-fidelity test data (Pathways, Exams, etc.)
05 · Development

Development

bun dev # Start dev server (http://localhost:3000) bun run lint # Run ESLint bun run type-check # TypeScript type checking bun test # Run tests
