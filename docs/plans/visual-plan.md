# Public Pages Visual Enhancement Plan

## Overview

Professional, minimalist imagery for Aerojet Academy's public-facing pages. Direction: muted tones, clean compositions, cool palette (blues/grays/whites), editorial/documentary photography style. Non-color-blocking, non-saturated. Befitting a world-class EASA Approved Training Organisation.

---

## Image Generation Settings (All images)

| Setting | Value |
|---------|-------|
| Style | Photorealistic, editorial/documentary photography |
| Lighting | Natural, soft, diffused (no harsh flash) |
| Color grade | Cool, desaturated, professional |
| People | Predominantly Black African, diverse ages, natural poses |
| Composition | Clean negative space for text overlays on heroes |
| Format | `.webp`, quality 80 |
| No | Text, watermarks, logos, branding in generated images |
